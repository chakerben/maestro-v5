# maestro-pm

Product management, FR/EN/AR.

## Skills

- `00-prd` — interview-first PRD with shadow-pass (blind spots incl. KSA
  compliance), measurable success metrics
- `01-user-stories` — Given/When/Then criteria, permissions criteria on
  every mutation, i18n as first-class stories
- `02-specs` — architect-posture technical specs: Zod contracts, migration
  reversibility, auth per endpoint
- `03-ticket` — a finding becomes one Trello card (🔴🟠🟡⚪ priority, repro /
  attendu / critères / pistes, labels quality|fast), batch-approved, never a
  fix. Board and list come from the plugin's user config.
