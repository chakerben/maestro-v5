# maestro-pm

Product management, EN/FR/AR: PRD and ticket templates ship in the three languages; prose rules per language in `04-writing/references/`.

## Skills

- `00-prd` — interview-first PRD with shadow-pass (blind spots incl. KSA
  compliance), measurable success metrics
- `01-user-stories` — Given/When/Then criteria, permissions criteria on
  every mutation, i18n as first-class stories
- `02-specs` — architect-posture technical specs, only for a new
  table/collection, external contract or auth change: Prisma/Firestore/SQL
  data model, Zod/Dart/OpenAPI contracts, migration reversibility, auth per
  endpoint
- `03-ticket` — a finding becomes one Trello card (🔴🟠🟡⚪ priority, repro /
  expected / criteria / leads, labels quality|fast; FR/EN/AR card template),
  batch-approved, never a fix. Board and list come from the plugin's user
  config.
- `04-writing` — prose rules for anything a human reads: direct, committed,
  no AI tells; Arabic and French rules in `references/`; `rewrite` mode
